# Pirate Legend
Unofficial One Piece fan game. Open index.html with game.js in the same folder. For GitHub Pages, upload both files to a repository, then Settings > Pages > Deploy from a branch > main / root. No dependencies. Rarity and combat values are fan-made; the catalogue is extensive but not verified exhaustive.

Crew update: choose an existing crew or recruit 1–10 unique characters as captain of a custom crew. Crew membership is cosmetic. The roster is a curated selection, including some film characters, not an exhaustive canon index. Enemies have a once-per-battle special attack. Large roster wheels have a full text legend below them.
